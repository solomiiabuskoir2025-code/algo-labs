# Lab 1

## Тема
Пошук k-того найбільшого елемента в масиві

## Умова задачі
Написати функцію для пошуку k-того найбільшого елемента в заданому масиві цілих чисел.

Параметр k задається на вхід функції і визначає порядковий номер найбільшого елемента:
- k = 1 → найбільший елемент
- k = 2 → другий за величиною
- k = 3 → третій за величиною і т.д.

## Вхідні дані
- Масив цілих чисел
- Число k

## Вимоги
- Розмір масиву повинен бути не менше k
- Програма повинна знайти:
  - k-тий найбільший елемент
  - його позицію (індекс) у масиві

## Приклад

Вхід:
[15, 7, 22, 9, 36, 2, 42, 18]
k = 3

Вихід:
3-й найбільший елемент: 22
Позиція в масиві: 2

## Опис розв'язку
Алгоритм роботи:
1. Створюється копія масиву
2. Масив сортується у спадному порядку
3. Визначається k-тий найбільший елемент
4. Знаходиться індекс цього елемента у початковому масиві

## Як запустити програму
1. Відкрити термінал
2. Перейти в папку з проєктом
3. Виконати команду:

python main.py

## Тестування
Для перевірки правильності роботи використовується бібліотека unittest.

Запуск тестів:

python -m unittest test.py
