# Lab 2

## Тема
Знаходження максимальної мінімальної відстані між коровами

## Умова задачі
Фермер Джон побудував загін з N секцій, які розташовані вздовж прямої лінії.

Є C агресивних корів, яких потрібно розмістити в цих секціях так, щоб мінімальна відстань між будь-якими двома коровами була максимальною.

Потрібно знайти найбільшу можливу мінімальну відстань.

## Вхідні дані
- N — кількість секцій (2 ≤ N ≤ 100000)
- C — кількість корів (2 ≤ C ≤ N)
- Масив координат секцій:
  free_sections = [x1, x2, ..., xN]

## Вихідні дані
- Максимальна мінімальна відстань між коровами

## Приклад

Вхід:
N = 5  
C = 3  
free_sections = [1, 2, 8, 4, 9]

Вихід:
3

## Пояснення
Коров можна розмістити, наприклад, у секціях:
- 1, 4, 8  
або  
- 1, 4, 9  

У цих випадках мінімальна відстань між коровами дорівнює 3, що є максимально можливим значенням.

## Опис розв'язку
Алгоритм:
1. Відсортувати масив координат
2. Використати бінарний пошук для знаходження максимальної мінімальної відстані
3. Перевіряти, чи можна розмістити C корів з певною мінімальною відстанню
4. Обрати найбільше можливе значення

## Як запустити програму

2. Перейти в папку з проєктом
3. Виконати команду:

python main.py
