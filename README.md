# Lab 5
Тема: Обчислення кількості островів у двійковій матриці  

##  Постановка задачі
Дано двійкову матрицю, де:
- 0 означає воду,
- 1 означає сушу.  

З’єднані числа 1 (по вертикалі та горизонталі) утворюють острів.  
Необхідно підрахувати загальну кількість островів.
У наведеній матриці є 5 островів.


##  Реалізація
Алгоритм реалізовано за допомогою BFS (Breadth-First Search):
- Використовується черга (`collections.deque`).
- Кожна клітинка суші позначається як відвідана.
- Кількість запусків BFS дорівнює кількості островів.
