# Lab 4

## Опис проєкту

Цей проєкт реалізує структуру даних черга з пріоритетами на основі AVL-дерева.

У даній реалізації кожен вузол дерева містить:
- значення (value)
- пріоритет (priority)

AVL-дерево автоматично підтримує балансування, що забезпечує ефективні операції вставки та видалення.


## Правило впорядкування

Для кожного вузла виконується умова:
- пріоритет батьківського елемента вищий, ніж у правої дитини  
  або
- пріоритет батьківського елемента менший або рівний, ніж у лівої дитини


## Підтримувані операції

1. Вставка елемента
   - додає елемент із заданим значенням та пріоритетом у чергу

2. Видалення елемента з найвищим пріоритетом
   - знаходить елемент з максимальним пріоритетом
   - видаляє його з дерева
   - повертає його значення

3. Перегляд черги
   - дозволяє переглянути всі елементи без змін структури дерева

## Реалізація

Проєкт побудований на основі AVL-дерева, яке:
- автоматично балансується після вставки та видалення
- гарантує складність операцій O(log n)

Кожен вузол реалізовано через клас Node, який містить:
- value — значення елемента
- priority — пріоритет елемента
- left, right — дочірні вузли
- height — висота вузла для балансування
